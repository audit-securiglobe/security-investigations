# Security Investigations

A collection of independent cybersecurity research, technical analyses, and real-world investigations into web security, browser ecosystems, phishing, third-party dependencies, and emerging attack techniques.

Each investigation documents the methodology, observations, and findings to encourage transparent and evidence-based security research.

All findings are published regardless of whether the results confirm or disprove the original hypothesis.
